# Implementation Plan: React Frontend CI/CD Deployment

**Branch**: `002-deploy-web` | **Date**: 2026-05-18 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/002-deploy-web/spec.md`

## Summary

Add `.github/workflows/002-deploy-web.yml` — a GitHub Actions workflow that installs Node.js 20.x, runs `npm ci` and `npm run build` (with `VITE_API_URL` injected at build time from the per-environment GitHub variable), then deploys the pre-built `dist/` folder to the matching Azure Static Web App via `Azure/static-web-apps-deploy@v1`. The workflow mirrors the trigger, concurrency, and environment-selection pattern of `001-deploy-infra.yml` exactly. PR preview deployments are explicitly out of scope.

## Technical Context

**Language/Version**: YAML (GitHub Actions workflow syntax); Node.js 20.x; React 18 + Vite  
**Primary Dependencies**: `actions/checkout@v4`, `actions/setup-node@v4`, `azure/login@v1`, `Azure/static-web-apps-deploy@v1`  
**Storage**: N/A  
**Testing**: `npm run build` (zero-error gate before deploy); GitHub Actions run-status UI  
**Target Platform**: GitHub Actions `ubuntu-latest` runners; Azure Static Web Apps (one instance per environment)  
**Project Type**: CI/CD pipeline (single GitHub Actions workflow file)  
**Performance Goals**: End-to-end deployment (code push → live site) within 25 minutes (SC-004)  
**Constraints**: `AZURE_STATIC_WEB_APPS_API_TOKEN` stored as per-environment secret in each GitHub Environment (`dev`, `qa`, `prod`); `skip_app_build: true` required (build runs in Actions, not on the SWA platform); `VITE_API_URL` must be env-injected on the build step; PR preview deployments are out of scope (FR-012)  
**Scale/Scope**: 1 workflow file; 3 environments; 1 job per run; one-week sprint
